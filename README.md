# LAPOP

> 一个把零散想法变成可视关系网的本地优先 AI 工具。输入一句话，AI 帮你讨论、拆解、落图；多个想法交叉关联，最终汇成一张全局知识图谱。

在线地址：**https://yangxj-154.github.io/lapop/**

---

## 一、使用背景

我们每天都有大量一闪而过的念头：一个产品点子、一段读书感悟、一个待解决的技术问题。它们通常散落在微信、备忘录、聊天记录里，时间一久就淹没、遗忘，更别说互相碰撞出新的东西。

传统笔记是**线性的**——你写一段、再写一段，但想法之间真实的联系是**网状的**。当你三个月后想找回"当时那个关于 X 的灵感"，往往翻不到。

**LAPOP** 想做的事很简单：

- 让想法**一输入就被结构化**——AI 帮你拆成"想法 / 方向 / 步骤 / 资料 / 洞察"，而不是一堆流水文字；
- 让想法之间**自动连成网**——隐藏的实体关联由 AI 帮你发现，并补全缺漏、理顺关系；
- 让所有内容**留在你自己的设备上**——不建账号、不上传服务器、不花存储费，AI 用你自己的 Key 跑。

它适合：个人知识管理、写作大纲、产品 / 创业构思、学习笔记梳理、把一段长聊天记录沉淀成可复用的图谱。

## 二、核心能力

| 能力 | 说明 |
|---|---|
| 想法拆解成图 | 一句话想法进入 AI 协同对话，拆解成五类节点（想法 / 方向 / 步骤 / 资料 / 洞察）自动落图，用颜色区分语义 |
| 卡片下钻深挖 | 选中任意卡片，AI 围绕它深度补全子节点，逐层展开，越聊越深 |
| 智能关联与优化 | AI 自动识别卡片间实体重叠、补全缺漏、理顺关系；生成关系图谱与数据面板，一眼看清单卡分布、类型占比、跨想法连接 |
| 导入与沉淀 | 导入文章 / 笔记 / 聊天记录成图谱，一键生成结构化思考报告（可复制、可下载 Markdown） |
| 联网搜索（可选） | 模型侧 web_search 工具，或应用侧 RAG（Tavily / SerpAPI / Bing），检索失败会静默退化为纯模型回答 |
| 撤销与重做 | 增删、连线、优化、导入、拖动都进入历史栈，工具栏按钮与 Ctrl+Z / Ctrl+Shift+Z 均可操作 |
| 本地优先 | 数据存浏览器 IndexedDB，自动保存（防抖 400ms），刷新不丢；PWA 可安装、可离线；节点正文支持 Markdown 渲染与长文折叠 |

## 三、操作说明

### 1. 第一次打开：填 API Key
画布右上角「设置」里填入你的 **API Key**（默认 DeepSeek，也支持任意 OpenAI 兼容接口）。
- **BaseURL**：模型厂商的兼容接口地址（如 `https://api.deepseek.com`）。
- **API Key**：你的密钥，**仅存本机，不上传**。
- **模型名**：填你实际订阅的模型（如 `deepseek-chat`）。
- **启动即清空**：默认关闭，这样每次打开都保留你上次的画布。

未填 Key 时走**演示模式**，返回占位内容预览交互形态；填了 Key 才是真思考。

### 2. 添加一个想法
左侧 AI 面板写下你的念头，回车或点「讨论」。AI 会先和你对话、澄清，再拆成**横向树状节点**挂到画布。首次打开会自动弹出欢迎引导，之后点右下角版本号可重新查看。

### 3. 与卡片下钻
点任意卡片上的名称弹出小窗看说明；在小窗里继续发问，AI 的回答**挂在这张卡片之下**，形成层级。卡片正文支持 **Markdown**，长文可展开 / 收起。

### 4. 编辑卡片
- **双击**卡片正文即可改文字；
- 顶部下拉可切换**节点类型**（想法 / 方向 / 步骤 / 资料 / 洞察）；
- 右上标记**已读 / 未读**；
- 删除该卡片同时清掉它的连线。

### 5. 插入链接与图片
卡片可挂网址、可插图，资料节点图文并茂；图片转 **base64 存本机**，不上传任何服务器。

### 6. 导入文件 / 聊天记录 → 自动拆解
AI 面板「导入」可粘贴文本，或上传 `.md` / `.txt` / `.docx` / `.pdf`，也能导入其他 AI 的聊天记录（ChatGPT / Claude / DeepSeek / 豆包等导出）。点「拆解成图谱」即可落图，新想法自动排在画布最右，避免重叠。

### 7. 优化画布
AI 面板「优化画布」：
- **整图模式**：审查全部节点，补缺失方向、修正错误连线；
- **选中模式**：先点选某张卡片再优化，只对该分支做深度补全。

优化后自动跑一次「**自动关联**」，把潜在的跨想法联系连上。

### 8. 关系图谱与数据面板
工具栏可查看**跨想法关联列表**、节点总数与各类型分布，点击任意项画布自动聚焦。

### 9. 撤销与重做
导图区缩放控件列有**撤销 / 重做**按钮，也可用 Ctrl+Z / Ctrl+Shift+Z。保存状态在每次自动保存后于画布正上方居中短暂提示。

### 10. 安装到桌面（PWA）
用 Chrome / Edge 打开地址，地址栏右侧点「安装」；手机用「添加到主屏幕」。之后断网也能打开，数据从本地读取，体验接近原生 App。

### 11. 清空与导出
- **清空**：应用内确认弹窗，删除全部卡片与连线（不可撤销，请先导出）。
- **导出**：顶栏「导出」可下载 JSON（完整备份）/ Markdown（思考报告）/ PNG（图谱图片）。

### 12. 联网搜索（可选）
设置里有「联网搜索」分组，两种模式：**模型侧**勾选后请求携带 web_search 工具；**应用侧**选 Tavily / SerpAPI / Bing 并填 Key，AI 回答前先检索资料注入上下文。

## 四、隐私与成本

- **数据本地化**：所有想法、图片、聊天记录都存在你浏览器的 IndexedDB，不出本机，只有你能访问。
- **AI 成本自付**：推理费由你自己的 API Key 承担，本工具不收任何费用、不替你买存储。
- **模型直连**：应用直连你配置的模型厂商 `/chat/completions` 接口，数据不经过任何中间服务器，本项目服务端（GitHub Pages）看不到你的任何内容。
- **免下载**：网页 + PWA，点链接即用，无需安装桌面软件。
- **免费托管**：部署在 GitHub Pages，自动 HTTPS，地址永久有效。
- **风险提示**：清缓存、换设备、无痕模式会丢失本地数据——重要画布请定期「导出」JSON 备份，或等待后续云端同步版本。

## 五、技术栈

Vite · React 18 · React Flow（@xyflow/react v12）· Zustand · idb-keyval（IndexedDB）· vite-plugin-pwa（Workbox）。

AI 调用 OpenAI 兼容接口（默认 DeepSeek），前端直连，无后端服务器；联网搜索封装在 `src/search.js`（Tavily / SerpAPI / Bing，12 秒超时）；节点 Markdown 采用零依赖的安全渲染，不注入原始 HTML，链接仅放行 http/https/相对路径以防 XSS。
