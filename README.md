# 想法画布 · Idea Canvas

> 一个把零散想法变成可视关系网的本地优先 AI 工具。输入一句话，AI 帮你讨论、拆解、落图；多个想法交叉关联，最终汇成一张全局知识图谱。

在线地址：**https://yangxj-154.github.io/idea-canvas/**

---

## 一、使用背景

我们每天都有大量一闪而过的念头：一个产品点子、一段读书感悟、一个待解决的技术问题。它们通常散落在微信、备忘录、聊天记录里，时间一久就淹没、遗忘，更别说互相碰撞出新的东西。

传统笔记是**线性的**——你写一段、再写一段，但想法之间真实的联系是**网状的**。当你三个月后想找回"当时那个关于 X 的灵感"，往往翻不到。

**想法画布**想做的事很简单：
- 让想法**一输入就被结构化**——AI 帮你拆成"方向 / 步骤 / 资料 / 洞察"，而不是一堆流水文字；
- 让想法之间**自动连成网**——"龙穴暴乱"和"梦火·叙拉克斯"这种隐藏关联，由 AI 帮你发现；
- 让所有内容**留在你自己的设备上**——不建账号、不上传服务器、不花存储费，AI 用你自己的 Key 跑。

它适合：个人知识管理、写作大纲、产品/创业构思、学习笔记梳理、把一段长聊天记录沉淀成可复用的图谱。

## 二、核心能力

| 能力 | 说明 |
|---|---|
| 无限画布 | 自由拖拽、缩放，想法节点随意摆放，不被页面边界限制 |
| AI 讨论 + 拆解落图 | 输入想法→AI 与你讨论→一键拆成横向树状节点挂到画布 |
| 节点下钻 | 点任意卡片继续追问，拆解结果挂在其下，越聊越深 |
| 五种节点类型 | 想法 / 方向 / 步骤 / 资料 / 洞察，颜色区分、语义清晰 |
| 跨想法关联 | 不同想法之间的实体自动或手动连线，形成全局图谱 |
| 关系图谱 + 数据面板 | 一眼看清单卡分布、类型占比、跨想法连接 |
| 导入即拆解 | 粘贴文本 / 上传 md·txt·docx·pdf / 其他 AI 聊天记录→自动提炼成图谱 |
| 链接 / 插图 | 卡片可挂网址、可插图，资料节点图文并茂 |
| 已读未读 | 卡片阅读状态可见，沉淀过程有节奏 |
| 画布自我学习 | 你删改的节点会被记住，下次拆解自动规避同类问题 |
| 优化画布 | AI 审查整图，补漏节点、修正连线、让结构更完整 |
| PWA 可装 | 添加到主屏幕，离线也能开，体验接近原生 App |

## 三、操作说明

### 1. 第一次打开：填 API Key
画布右上角「设置」里填入你的 **DeepSeek API Key**（或其他 OpenAI 兼容接口）。
- Key 只存在你浏览器本地，**不落明文、不上传**。
- 「显示 / 隐藏」按钮可临场查看，用完建议切回隐藏。

### 2. 添加一个想法
顶部输入框写下你的念头（如"想做一个帮助独居老人的智能提醒产品"），回车或点「讨论」。
AI 会先和你对话、澄清，然后你可以点「拆解成图谱」，节点树自动落到画布右侧。

### 3. 与卡片下钻
点任意卡片上的名称 → 弹出小窗看详细说明；在小窗里继续发问，AI 的回答会**挂在这张卡片之下**，形成层级。

### 4. 编辑卡片
- **双击**卡片正文即可改文字；
- 顶部下拉可切换**节点类型**（想法/方向/步骤/资料/洞察）；
- 右上「✓/●」标记**已读 / 未读**；
- 「×」删除该卡片（同时清掉它的连线）。

### 5. 插入链接
工具栏「🔗 链接」→ 粘贴 URL → 生成「资料」节点。卡片上的 🔗 点击即在新标签打开；创建时尽量抓取网页标题作说明。

### 6. 插入图片
卡片头部「🖼」选本地图片，转 base64 存本机，卡片显示缩略图，点开看大图。图片不上传任何服务器。

### 7. 导入文件 / 聊天记录 → 自动拆解
AI 面板「导入」→ 可粘贴文本，或上传 `.md / .txt / .docx / .pdf`。
- 文章、笔记：提炼成「想法 → 方向 → 步骤/资料/洞察」节点树；
- 其他 AI 的聊天记录（ChatGPT / Claude / DeepSeek / 豆包等导出）：按"对话主线 / 关键结论 / 待办 / 提到的资料"组织成图谱。
点「拆解成图谱」即可落图，新想法自动排在画布最右，避免重叠。

### 8. 关系图谱
工具栏「关系图谱」→ 查看跨想法关联列表与想法清单，点击任意项画布自动聚焦。

### 9. 数据面板
工具栏「数据面板」→ 看节点总数、各类型分布条，点击类型可筛选画布。

### 10. 优化画布
AI 面板「优化画布」：
- **整图模式**：AI 审查全部节点，补缺失方向、修正错误连线（激进模式，每个方向至少补一个节点）；
- **选中模式**：先点选某张卡片再优化，AI 只对该分支做深度补全。
优化后自动跑一次「自动关联」，把潜在的跨想法联系连上。

### 11. 安装到桌面（PWA）
用 Chrome / Edge 打开地址 → 地址栏右侧点「安装」；手机用「添加到主屏幕」。
之后断网也能打开，数据从本地读取，图标像一个普通 App。

### 12. 清空与导出
- 「清空」：应用内确认弹窗，删除全部卡片与连线（不可撤销，请先导出）。
- 导出：把当前画布存成 JSON 文件备份。

## 四、隐私与成本

- **数据本地化**：所有想法、图片、聊天记录都存在你浏览器的 IndexedDB，不出本机。
- **AI 成本自付**：推理费由你自己的 API Key 承担，本工具不收任何费用、不替你买存储。
- **免下载**：网页 + PWA，点链接即用，无需安装桌面软件。
- **免费托管**：部署在 GitHub Pages，自动 HTTPS，地址永久有效。

## 五、技术栈

Vite · React 18 · React Flow（@xyflow/react）· Zustand · idb-keyval（IndexedDB）· vite-plugin-pwa（Workbox）
AI 调用 OpenAI 兼容接口（默认 DeepSeek v4），前端直连，无后端服务器。
